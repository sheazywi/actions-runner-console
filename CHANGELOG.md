# Changelog

## 0.1.0

- Configurable Linux and Windows local dashboards for existing GitHub Actions runners.
- CPU/RAM/disk telemetry, job hooks, observed steps and masked output.
- Windows sharing-safe state reads/writes with a concurrency regression test.
- Standard-account systemd/Task Scheduler installation, reversible hooks and explicit console takeover.
- Persistent-build caching guidance; no automatic workspace or cache deletion.
